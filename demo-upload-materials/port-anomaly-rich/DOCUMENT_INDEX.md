# 文档索引与证据地图

`documents/` 是整理版，适合演示讲解；`text/` 是扁平版，适合上传控件不支持文件夹时使用。两边内容相同，都是 19 份文本材料。

## 00-公开来源

用途：交代素材来源、许可边界和安全值守要求。

- `00-公开来源与素材使用清单.txt`
  - 说明 AccessAIS、DVIDS、NOAA、Wikimedia 等来源。
  - 明确本案 AIS 是“字段样式合成记录”，不是 2026-07-01 次日下载的真实 AccessAIS 数据。
- `04-港口安保值守要求摘编.txt`
  - 说明夜间限制区车辆应保留登记表、OCR 截图、放行口令和补录审批。
  - 用来支撑“三号门缺补录审批”的研判。
- `18-真实多媒体素材下载索引.txt`
  - 列出真实图片、视频、音频参考来源和许可说明。

- `17-后续情况简报.txt`
  - 称现场未发现异常卸货。

## 建议演示流程

1. 上传 `documents/` 或 `text/` 下的 19 份文本材料。
2. 上传 `media/` 下的图片、WAV、MP4。
3. 等文本材料完成切块；视频较大，可让它后台处理。
4. 提问“这批材料里最关键的矛盾是什么？”。
5. 再提问“LH-7712 是否存在违规拆封或转运迹象？”。
6. 创建结论并生成报告。
