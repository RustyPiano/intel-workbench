# 功能与验证记录

## 已实现功能

- 专题内统一管理原始素材、文本切块、转写、问答、矛盾、结论和报告。
- 原始文件与证据集合使用 SHA-256 标识；引用由服务端核对原文片段和文件版本。
- 结论保存修订版本、复核意见及未决问题；报告保存独立的 Markdown、DOCX 和内容校验值。
- 管理员分配编辑者和复核者，服务端检查身份、专题权限、密级和复核权限。
- 登录使用服务端会话 Cookie，修改请求校验 CSRF token。
- 关键操作写入哈希审计记录，程序启动时检查记录连续性。
- 模型和媒体请求按 OfflineGuard 配置的服务器名单检查。

## 2026 年 7 月评估记录

- 冻结合成数据集上的矛盾检测 Precision 为 1.000、Recall 为 0.750、F1 为 0.857；当时设定的召回要求为 0.80。
- Agent 合成评估的答案正确率为 0.900，拒答正确率为 0.500，候选结论支撑率为 0.855。
- 同配置端到端测试有一次未检出关键冲突、一次通过；通过的运行保存了完整结果。
- 当时的最终镜像扫描有 191 项未处理的高危或严重问题，其中严重问题 26 项、高危问题 165 项。

数据集为人工编写的虚构案例。模型、运行版本、原始结果及验证范围见[完整评估](report/2026-07-26-practical-trustworthiness-assessment.md)。

## 运行条件

存储适用于单机单进程。模型、音频、图像、向量和重排服务需要按配置提供；未配置时的行为见[运行手册](how-to/run-the-workbench.md)。应用层服务器名单检查的范围是已接入的模型和媒体请求；进程与网络隔离由部署环境设置。通用运行时的 Bash 工具具有本机命令执行权限，工作台的模型工具集已排除该工具。
