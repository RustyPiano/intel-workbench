## 风险管理

### 风险监控

| 风险 | 触发条件 | 应对措施 |
|------|---------|---------|
| 建议采纳率低 | < 50% | 回退规则引擎，暂停 LLM 生成 |
| LLM 质量不稳定 | 相关性 < 60% | 增加重试次数，优化提示词 |
| 性能劣化 | 响应时间 > 5s | 增加缓存，异步处理 |
| 测试失败 | 任何测试失败 | 立即修复，不进入下一阶段 |

### 回滚计划

每个阶段都可以独立回滚，不影响已有功能：

- **阶段 1 回滚**: 删除 SuggestionService，恢复原有 UI
- **阶段 2 回滚**: 禁用 LLM 生成，保留规则引擎
- **阶段 3 回滚**: 禁用 AI 助手，保留建议功能
