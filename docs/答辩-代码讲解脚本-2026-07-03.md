> 场景：老师说"打开你的代码看看 / 讲讲这块怎么实现的"。你不熟这套代码没关系——**按本脚本走**：先给地图夺回主动权，再对高概率追问逐个导览。每段都标了**打开哪个文件、指哪个函数、念什么话、追问怎么接**。
> 记忆主线（每次讲解都回到它）：**"LLM 只是可替换组件，判定框架/证据链是我们自研的。"**

## 一、三条讲代码的总策略（先记住）

1. **先意图，后代码**（altitude first）。先说"这段要解决什么问题、为什么这么设计"，再落到函数。老师要看的是你**懂不懂设计**，不是背行号。
2. **用"文件名 + 函数名"做锚，不背行号**。行号会变，函数名不会。说"在 `contradiction-service.ts` 的 `clusterClaims`"，比说"第 732 行"稳。
3. **不确定就当场翻代码，别硬编**。诚实话术："这块具体实现我翻一下——"然后打开文件找到函数。**当场能定位到函数**本身就是加分（证明你熟结构）；硬背背错才扣分。

## 三、高概率追问 · 逐个导览脚本

### A. 矛盾检测（最可能被深挖，重点准备）
**打开**：`packages/server/src/analysis/contradiction-service.ts`
**一句话总纲**："核心是**别让 LLM 一把梭找矛盾**，而是拆成四步，把 LLM 关进'单点语义判定'这一小格，其余全是确定性算法。"

**① 抽取**——指 `extractClaims`（≈694）+ `groundClaims`（≈702）
> "第一步逐块抽原子主张 `{实体, 属性, 取值, chunk_id}`，用的是 `generateJson`，注意这里 **`thinking: "disabled"`**——机械抽取关思考求速度。抽完立刻过 `groundClaims`，用 `resolveValidCitations` **把 LLM 幻造的、对不上真实 chunk 的锚点全丢掉**，只留能绑定真实原文的主张。这就杜绝了'凭空捏造证据'。"

**② 聚类（非 LLM，最能打的一段）**——指 `clusterClaims`（≈732），**就 8 行**
```ts
private clusterClaims(claims) {
  const clusters = new Map();
  for (const claim of claims) {
    const key = claim.normalized_entity;      // 归一化实体做 key
    clusters.set(key, [...(clusters.get(key) ?? []), claim]);
  }
  return clusters;
}
```
> "聚类是**纯 `Map` 分组、零 LLM**——按归一化实体把讲同一个对象的主张聚到一起。归一化在 `normalizeEntity`，走案内 `elements.json` 的别名表（比如'苏E7K31'的各种写法归一）。**这一步完全确定性、可复现。**"

**③ 只在簇内成对判定**——指 `judgeClusters`（≈741）里这一行核心：
```ts
const judge = cheapJudgePair(claimA, claimB) ?? await this.judgePair(actor, claimA, claimB, signal);
```
> "只在**同一实体簇内**两两比，复杂度是 O(每簇内²) 而不是全语料 O(N²)。而且比之前先过 `cheapJudgePair`——**确定性规则短路**：数值相等直接判'一致'，`open/closed`、`present/absent` 这类反义状态词直接判'矛盾'（看 `cheapJudgePair` ≈167 的反义词表）。**只有规则拿不准，才落到 `judgePair` 调 LLM 做 NLI 判定**。"

**④ 确定性置信度**——指 `confidence`（≈790），**一个公式**
```ts
confidence = certainty*0.5 + (跨源 ? 0.3 : 0) + 数值距离奖励
```
> "置信度不是让 LLM 拍脑袋给，是**确定性公式**：语义确定度占一半，**跨素材冲突加权**（跨源冲突更值得警惕），数值差得越大加得越多。最后 `makeContradiction`（≈794）把两端主张各绑 `content_hash` 出处、标 `cross/intra-material` 范围。"

**收尾金句**：
> "所以流程里 **LLM 只出现在两处：单块抽主张、单对语义判定**，都是可替换的组件；聚类、短路规则、置信度、批处理合并全是我们的确定性算法。这就是'非套壳'的边界。"

**预判追问**：
- **"thinking 为什么关？"** → 指 `judgePair`（≈785）的注释：benchmark 实测**开思考召回反降**（F1 0.909 vs 关思考 0.957），所以 env `MINI_AGENT_CONTRADICTION_JUDGE_THINKING` 默认关、可切开复现。**这是数据驱动决策，不是拍脑袋。**
- **"语料大了会不会爆？"** → `detectFromChunks` 对全案 chunk **按 40 块/批、并发 4** 跑，结果确定性拼接合并，不会一次性丢上下文。
- **"每次跑结果一样吗？"** → 聚类/规则/合并确定性；同输入两跑对 canonical JSON 做 sha256 相等（有一致性测试）。

### B. 溯源问答的"证据接地"（防幻觉的核心）
**打开**：`packages/server/src/inquiry/intel-harness.ts`
**指** `cite` 工具（≈393）
> "问答不是把片段丢给 LLM 就完了。模型想引用任何一句，必须调 `cite(chunk_id, claim, quote)`，这里有**双重校验**：① `sha256(片段) === content_hash`——**防篡改**；② `quote` 必须是原文里**逐字出现的子串**（`indexOf(quote) >= 0`），不能省略号、不能自己拼。两条都过才发一个 `cite_id`。"

**再指** `finalize_answer`（≈467）
> "最终答案的**唯一出口**是 `finalize_answer`，每条结论的 `cite_ids` 必须是前面 `cite` 返回的 id。**没经过这里的自然语言草稿一律丢弃**——模型没法'偷偷夹带'没接地的话。"

**加一句多模态**：
> "音视频是**按需**读的——`transcribe`/`ocr_region`/`caption_frame` 每次调外部模型前，都先过 `guard.authorize` 记审计（≈513/574），产出的转写片段自己也带 `content_hash`，可以继续被 cite。"

**预判追问 "这跟直接问 GPT 差在哪"** → 就答这套：强制接地 + 哈希校验 + 逐字引用 + 未接地即丢弃，GPT 直出给不了。

### C. 零外发红线 OfflineGuard
**打开**：`packages/server/src/security/offline-guard.ts`（**很短，才 47 行，敢让老师看全**）
**指** `authorize`（≈27）
> "每个要出网的地方——调 LLM、调 OCR/ASR——都得先调 `authorize(url, {user, purpose})`。它**先无条件写一条审计**（`egress.allow` 或 `egress.deny`），再判断这个 host 在不在白名单，不在就抛 403。白名单是构造时传进来的、**只含已配置的本地/内网端点 host**（在 `app.ts` 拼），没配的一律拒。"

**主动交代边界（诚实加分）**：
> "我要诚实说一点：它是**应用层协作式闸门**，覆盖我们所有应用出站点并留痕，但**不承诺拦操作系统或第三方库的越界出网**——代码注释里我写明了。气隙部署时靠物理断网兜底。"

### D. 审计哈希链
**打开**：`packages/server/src/audit/audit-service.ts`
**指** append 里的 `event_hash`（≈89）和 `verify`（≈134）
> "每条审计 `event_hash = sha256(payload_hash + 上一条的 event_hash)`，链式串起来。`verify()` 逐条重算比对，改任何一条历史记录都会断链、能定位到 `brokenAt`。有真实测试：改一条落盘记录的 user 字段但不改哈希，verify 立刻报 `ok:false`。"
> 补一句时序："而且是**先落业务产物、再 append 审计**，注释里标了这是提交点。"

## 四、"这是你写的吗 / 是不是套壳？"专项应对

**标准回答**：
> "自研的是：**Agent Runtime、检索融合、矛盾检测的判定算法、审计哈希链、导出零捏造闸、受控问答工具集**。外部依赖的只有**模型服务**——LLM、Embedding、OCR、ASR，它们都走标准接口（OpenAI 兼容 / HTTP），**可整体替换成本地开源模型**。我们的价值在**判定框架和证据链**，模型只是可插拔的组件。"

**如果被追问细节证明**（打开代码指给他看）：
- 指 `clusterClaims`（8 行纯算法）、`cheapJudgePair`（规则表）、`confidence`（公式）——"这些**没有一行调 LLM**，都是我写的确定性逻辑。"
- 指 `judgePair` 里**注释引用了自己的 benchmark 数字**做设计决策——"如果是套壳，不会有这种'我跑了对照实验所以默认关思考'的注释。"
- 提测试："101 个测试文件、783 个用例，当前全绿；矛盾检测有带标注语料的 benchmark。"

## 五、不会/记不清时的话术（照抄）

- "这块的具体实现我翻一下代码——"（**当场打开文件，找到函数**。定位到就已经赢一半。）
